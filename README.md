# 🌱 AgriTech Connect

### AI-Powered Agricultural Innovation Platform

AgriTech Connect is a hackathon project that addresses
two important challenges in agriculture and aquaculture.

## 🐟 Project 1: AquaGuard AI

An early water-quality risk monitoring system for
small aquaculture farms.

Features:
- Water pH monitoring
- Temperature monitoring
- Dissolved oxygen checks
- Water-quality risk alerts
- Downloadable reports

## 🥬 Project 2: FarmDirect

A direct marketplace connecting farmers with buyers.

Features:
- Farmer produce listings
- Product search
- Price comparison
- Buyer enquiries
- Location-based product discovery

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- Machine Learning (planned)
- GitHub

## 🎯 Objective

To develop affordable digital tools that help
farmers make informed decisions and improve
market access.
